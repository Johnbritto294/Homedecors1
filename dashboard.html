Frequently Asked Questions

How do I reset my store profile password? +
Navigate to the Dashboard Settings view using the sidebar options. Click on the Security sub-tab, enter a new password inside the text boxes, verify its strength level with the meter bar, and click Save Settings.
How do carbon-neutral orders calculate shipments? +
Stackly integrates with FedEx APIs. Low carbon shipping is calculated based on parcel coordinate proximity and total shipping package mass volume indices.
Can I edit order contents after customer checkout? +
If the order is still under "Processing" status, click on the Order ID, select edit line details, modify pricing/qty as necessary, and update changes.
